# Machine Learning Internship Task 

This repository contains key machine learning tasks completed during my internship, showcasing end-to-end work in data preparation, feature engineering, model development, and evaluation.  

## 📌 Tasks  

- **Task 1 – Email Spam Detection:** Built a spam email classifier using TF-IDF features and ML models.  
- **Task 2 – MNIST Digit Recognition:** Handwritten digit classification with CNN/ANN models.  
- **Task 3 – Housing Price Prediction:** Predicted California housing prices with RandomForest & XGBoost.  
- **Task 4 – Iris Flower Classification:** Classified iris species using classic ML algorithms.
  
This portfolio highlights practical applications of machine learning techniques developed during my internship.
